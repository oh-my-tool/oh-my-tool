# @oh-my-tool/sdk

The Bun-first SDK for creating Oh My Tool native extensions.

```powershell
npm install --save @oh-my-tool/sdk
```

Extensions expose an `ExtensionManifest` and handlers through
`defineExtension`. See the main [Oh My Tool repository](https://github.com/oh-my-tool/oh-my-tool)
for the manifest contract, extension examples, and compatibility policy.

Requires Bun 1.4 or newer.
