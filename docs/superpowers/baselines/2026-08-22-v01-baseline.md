## Current CLI contract

```text
binary:          omt
execution verb:  call
home override:   OMT_HOME
default state:   ~/.omt (or %USERPROFILE%\\.omt on Windows)
```

The current smoke and E2E tests cover install, search, describe, call, extension listing, and policy rejection. The independent extension manifests expose `mysql.query`, `mysql.schema`, `mysql.explain`, `redis.ping`, `redis.get`, `redis.scan`, and `redis.info`.
