# Governance

Oh My Tool is maintained by the `oh-my-tool` organization.

Maintainers review pull requests, manage releases, and protect compatibility,
security, and project direction. Significant changes to the SDK contract,
extension trust model, release policy, or provider architecture should begin as
a GitHub Discussion or design issue before implementation.

Maintainers make decisions by consensus where possible. When consensus is not
reached, the release maintainers make the final decision and document the
rationale in the relevant issue or pull request.
